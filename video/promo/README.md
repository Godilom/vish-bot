# Рекламный ролик «Бот ВИШ» (Remotion)

Вертикальный ролик 1080×1920, 30 fps, ≈88 с. Сценарий — `PROMPT.md` в папке проекта
(`video/ad-vish-bot/PROMPT.md`), по нему 12 сцен:

| Сцена | Файл | Что показывает |
|---|---|---|
| 0 | `S0Hook` | Обложка: аватар, иконки функций, «Всё расписание ВИШ — в одном чате» |
| 1 | `S1Start` | `/start` → выбор группы → рекомендуемые уведомления → «🖼 Картинкой» |
| 2 | `S2Days` | «📅 Сегодня», «📅 Завтра», «🗓 Неделя» |
| 3 | `S3Stream` | «🔍 Найти с ИИ» → «🎓 Поток», меню потока, «◀️ В меню» |
| 4 | `S4Student` | «🕵️ Где студент» → Беляев Василий |
| 5 | `S5Teacher` | «👨‍🏫 Где препод» → Петров Кирилл Алексеевич, «👁 Следить за преподом» |
| 6 | `S6Calendar` | «🗂 Ещё» → «📆 Календарь телефона» → подписка → iOS «Календарь» |
| 7 | `S7Changes` | Пуш на экране блокировки → картинка изменений → календарь обновился |
| 8 | `S8Settings` | «⚙️ Настройки» → «🖼 Вид расписания»: 4 темы и формат (превью — монтажная вставка) |
| 9 | `S9Buttons` | «⌨️ Нижнее меню» → «🧩 Кнопки внизу» → меню 3 × 3 |
| 10 | `S10Ai` | «💬 Спросить ИИ»: вопрос летит в аватар, схема бот ⇄ ИИ ⇄ бот ⇄ база, ответ |
| 11 | `S11Final` | Логотип и список функций |

Экраны Telegram рисуются кодом (`src/ui/Chat.tsx`) по сценарию сообщений: появление, правка
на месте, нажатия с розовой рамкой и кругом касания, всплывашки, нижнее меню, набор текста.
Подписи кнопок и тексты бота сняты из кода бота (`src/bot/keyboards.ts`, `src/bot/handlers/*`).

Картинки расписания (`public/posters`) нарисованы **кодом бота** (`src/render`) по
придуманному расписанию ВИШ-14-24 на 26 ноября 2026:

```bash
npm ci                                       # в корне репозитория
npx tsx video/promo/tools/render-posters.mts # из корня
```

Схема в сцене ИИ сверена с `src/bot/handlers/ask.ts` и `src/ai/ask.ts`: ИИ сам в базу не ходит,
он вызывает инструменты (`find_subject`, `get_schedule` …), а бот выполняет их у себя.

## Запуск

```bash
npm ci
npm run dev                                          # Remotion Studio
npx remotion render Promo out/vish-bot-promo.mp4     # весь ролик
npx remotion render S10Ai out/ai.mp4                 # одна сцена
```

Вывод — H.264, yuv420p, BT.709, CRF 18 (`remotion.config.ts`). Шрифт Inter лежит в
`public/fonts` (OFL). Эмодзи берутся из системного шрифта: на Linux это Noto Color Emoji,
на другой системе они будут выглядеть по-другому. Если Remotion не может скачать свой
Chrome, укажите готовый: `--browser-executable=/путь/к/chrome-headless-shell`.

## Где что править

- Тайминги сцены — константы в начале файла сцены (кадр нажатия, появления сообщения).
- Длительность сцены — `S*_DURATION`; переходы — `src/Promo.tsx` (10 кадров).
- Подписи сверху — проп `caps` у `PhoneScene`.

# ВИШ AI

Второй Telegram-бот проекта: тонкий чат поверх Claude API. Живёт в этой папке
репозитория ВИШбота и деплоится отдельно (`.github/workflows/ai-bot.yml`):
правка здесь не перезапускает ВИШбота, правка ВИШбота не трогает ВИШ AI.

## Экономия

| Что | Как |
|---|---|
| Модель | `claude-haiku-5-5` — самая дешёвая из текущих ($0.10 / $0.50 за 1M токенов при промпте до 100K) |
| Effort | `low`, задан явно: у Haiku 5.5 умолчание `medium` |
| Ответ | `max_tokens` 10240 (размышление считается туда же; платится только написанное, потолок — ≈$0.005), промпт просит 1–5 предложений |
| История | 3 последние пары, забывается через 30 минут тишины; `/new` — сброс |
| Вход | сообщение длиннее 2000 символов обрезается |
| Лимит | 30 сообщений на человека в сутки; пока бот думает, второе сообщение не уходит в API |
| Файлы | 10 в сутки на человека; фото до 1280 px (≈1600 токенов), PDF до 10 стр., текст до 20 000 символов, до 10 МБ; в историю идёт только пометка «[PDF: имя]» |
| Кеш промптов | выключен сознательно: у Haiku 5.5 кешируется префикс от 512 токенов, наш короче, а окно истории сдвигается — запись в кеш стоит ×1,25 и не окупится |

Ещё дешевле: `AI_THINKING=off` (без размышления) или `AI_HISTORY_TURNS=0` (каждый вопрос с нуля).

## Файлы

Фото, картинки (JPEG, PNG, GIF, WebP), PDF и текстовые файлы (.txt, .md, .csv, код). Вопрос — в подписи к файлу.
.docx, .pptx и HEIC пока не читаются.

## Команды

- `/start` — приветствие
- `/new` — забыть разговор
- `/usage` — для `AI_ADMIN_IDS`: ответы, токены и примерная цена за сегодня

## Разработка

```
cd ai-bot
npm install
npm run typecheck && npm test && npm run build
cp .env.example .env   # вписать AI_BOT_TOKEN и ANTHROPIC_API_KEY
npm run dev
```

## Деплой

Сервер в той же панели Pterodactyl, egg **Node.js generic** (как у ВИШбота),
стартовый файл `index.js`. Секреты GitHub и `.env` — в `docs/DEPLOY.md`, раздел «ВИШ AI».
